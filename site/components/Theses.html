Therefore, successfully migration of a legacy application to the cloud requires careful consideration of technical, organizational, and economic factors. This thesis explores how cloud migration can be planned and implemented in the context of a legacy application. The study combines a literature review with an applied case study of a project management application developed with ASP.NET Framework and Microsoft SQL Server. The case study evaluates several migration alternatives, including direct deployment to an Azure virtual machine, deployment to Azure Container Instances, and hybrid alternative. The alternatives are compared based on technical feasibility, provisioning effort, resource usage, maintainability, portability, and estimated costs. The results show that replatforming can provide a practical way to modernize the deployment environment without redesigning the internal application architecture. The application layer was containerized with Docker, while the database was migrated to Azure SQL Database. This improved deployment consistency and repeatability. However, this thesis demonstrates that cloud migration does not automatically guarantee lower costs or eliminate infrastructure complexity. Its benefits depend on workload requirements, resource sizing, service requirements, existing infrastructure costs, and the extent of application modernization. Newer solutions offer smaller runtime sizes, more efficient rendering approaches, and often a better developer experience. Modern JavaScript frameworks have enabled the development of interactive and user-friendly web applications. Over the past decade, React has become the leading user interface framework in the JavaScript world, contributing to the rise of Single Page Applications (SPA). However, the extensive development of SPAs has led to an increase in the amount of client-side JavaScript, thus triggering performance issues in terms of initial loading times.
The speed at which a web application is initially rendered can significantly influence its potential for revenue generation, as the initial loading time often determines whether a user stays on or abandons a web page. Recognizing the integral role of the initial loading speed in user retention, this study delves into the realm of performance optimization strategies, focusing predominantly on the use of React-like UI frameworks and meta-frameworks as a means to improve the initial rendering performance of web applications. Through this exploration, we aim to provide a comprehensive understanding of contemporary rendering approaches and their role in enhancing web application performance.
To compare the performance impacts of various rendering approaches, we implement a React application simulating the dynamics of a real-world e-commerce platform and replicate the same application through multiple technologies. These technologies include the UI frameworks Preact, Qwik, and Solid, as well as the meta-frameworks Next, Astro, and Qwik City. Finally, we provide extensive benchmarks to measure the page weights and initial rendering performance of each application version.
Our findings demonstrate that the utilization of React-like UI frameworks and meta-frameworks can considerably decrease the amount of JavaScript downloaded by the client, contributing to improved initial rendering times. The most promising results are achieved by using meta-frameworks for extending the capabilities of UI frameworks with modern rendering strategies like Server-Side Rendering and Static Site Generation. However, these approaches often present significant trade-offs, such as increased Server Response Times and extended build durations.
